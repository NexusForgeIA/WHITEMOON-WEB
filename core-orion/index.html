¿En qué se diferencia Core Orion de Core Spark Web?
Core Spark Web (899€) incluye un Agente Spark conversacional 24/7 en la web. Core Orion (1.499€) sustituye ese agente por Orion IA, el agente de voz que atiende, gestiona citas y llamadas hablando con tus clientes sin intervención humana. Ambos incluyen la web profesional, dominio, SEO y GEO/AEO.
¿En cuánto tiempo está la web online?
5-7 días laborables. Reunión de diagnóstico y diseño los primeros días, desarrollo a mitad de semana y publicación con SEO técnico y Orion IA voz al final. Tu web es indexable en Google desde el día 1.
¿Hay permanencia?
No. Ningún pack de WhiteMoon tiene permanencia. La web es tuya, te entregamos el código fuente y el dominio, y basta con 30 días de aviso para cancelar la cuota mensual.
