Todo lo que necesitas saber sobre Spark

¿Qué incluye el Pack Spark?
Chatbot IA conversacional 24/7 entrenado con la información de tu negocio, captura automática de leads, panel de conversaciones y soporte humano. Cuota plana de 499€ setup + 199€/mes, sin permanencia.
¿Tiene permanencia o setup inicial?
No. Spark es 499€ setup + 199€/mes, sin permanencia. Cancelas cuando quieras avisando con antelación razonable. Los datos y conversaciones generados son tuyos.
¿En cuánto tiempo está activo el chatbot Spark?
En 5-7 días laborables. El día 1 recogemos información de tu negocio y el día 2 configuramos y probamos el Agente IA contigo hasta que quede perfecto.
¿Spark sirve si todavía no tengo web?
Sí. El Agente IA se instala como widget en tu web actual con un simple script que nosotros configuramos. Si todavía no tienes web, creamos una landing page profesional donde el Agente IA atiende a tus clientes desde el primer día. Para una web completa con SEO y GEO incluidos, el Pack Core Spark Web es la opción recomendada.
