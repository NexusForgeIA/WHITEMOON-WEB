Preguntas frecuentes

¿Qué es el WhiteMoon System?
El WhiteMoon System es la plataforma de automatización empresarial basada en IA de WhiteMoon Agencia. Está compuesto por cuatro pilares que trabajan juntos: Spark (agente IA en la web que ya tienes), Core Spark Web (web nueva con el agente IA dentro y SEO/GEO desde el primer día), ROI Engine (calculadoras gratuitas para medir el impacto económico real) y Coste de no automatizar (diagnóstico cuantificado de los 5 costes ocultos por no usar IA).
¿Cómo encajan los 4 pilares entre sí?
El sistema sigue un flujo natural. Coste de no automatizar abre la conversación cuantificando las pérdidas actuales. El ROI Engine atrae tráfico vía calculadoras que cuantifican pérdidas y oportunidades. Los hubs económicos (Costes, ROI, Ahorro) traducen ese impacto a soluciones. Spark da entrada rápida en pymes con web existente y Core Spark Web monta la web con el agente dentro para quien aún no la tiene. El agente atiende 24/7 y, si hay documentación propia, puede entrenarse con ella (RAG). Resultado: lead capturado, cualificado y entregado al CRM sin intervención humana.
¿En qué se diferencia de una agencia tradicional?
Una agencia tradicional vende servicios discretos (web, SEO, ads). El WhiteMoon System vende infraestructura conectada: cada pilar incrementa el valor del siguiente. Cuando un cliente entra por una calculadora del ROI Engine y termina con su agente IA en producción, no ha comprado piezas sueltas: ha desplegado un sistema completo. El proveedor (WhiteMoon) no es agencia: es operador de plataforma.
¿Cuánto tarda en estar operativo el sistema completo?
Spark y Core Spark Web están operativos en 7 días. ROI Engine y Coste de no automatizar: acceso inmediato (calculadoras gratuitas y públicas). Si el agente se entrena con mucha documentación propia, el plazo se fija en la propuesta según el volumen.
